## Cross-cutting defects corrected

1. **App screenshots used as photography** (04, 16, 17, 20, 37). Replaced with
   licensed photos of real community service.
2. **Duplicated/ghosted headings and metrics** (01, 05, 07, 12, 13, 15, 21, 29, 33).
   Rebuilt each header with one title block and one metric row.
3. **Contradictory impact totals** (03 vs 01 vs 13). One canonical record now feeds
   every screen and every test.
4. **Colour-only status.** Every status pairs colour with text and a shape/icon.
5. **Fixed 1600 × 1000 page heights.** Pages scroll inside the window; content is
   never squeezed by shrinking type.
