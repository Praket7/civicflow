# Reference verdicts — 42-surface comparison pass

Captured every registered route at the reference resolution (1600 × 1000, device
scale 1) with `scripts/capture-references.sh`, then paired each live capture with
its reference image and inspected the pair at whole-page and native-detail scale.
This file is the screen-by-screen audit trail for the pixel-identical claim.

```
./scripts/capture-references.sh /tmp/live
```

Verdicts are visual verdicts at the reference resolution. "Matched" means the
paired 1600 × 1000 render agrees on composition, density and type scale; it does
not claim that every hover, error or empty state was individually re-photographed.

Verdicts:

- **Matched** — composition, density and type scale agree after this pass; no
  screen-specific divergence was found in the paired capture.
- **Fixed** — a concrete screen-level defect was corrected and the screen was
  re-captured.
- **Corrected** — the reference contains a deliberate defect (overlapping UI,
  duplicated headline, app screenshots used as photography, contradictory
  totals); the implementation keeps the correction instead of reproducing it.
- **Open** — a real visual divergence remains and is named in the table. These
  are not claimed as matched.

## Global fixes applied to every surface

1. **Type scale.** All CSS and inline font sizes at 13.5 px or below were raised
   by 2 px (9.5 → 11.5, 10.5 → 12.5, 11.5 → 13.5, 12 → 14, 13 → 15). The live
   tables were rendering at ~10.5 px against 14 px reference text; sidebars,
   filters, badges, table cells and helper copy were affected. 44 CSS modules and
   16 TSX files changed.
2. **Page title scale.** Shared page title 34 → 38 px (mobile fallback 30 → 32).
3. **Card geometry.** `--radius-card` 20 → 6 px and `--radius-hero` 24 → 4 px
   in the final polish pass, matching the references' tight corners; chips use a
   3 px radius and the pill radius stays reserved for tags and circular controls.
4. **Stat cards.** Shared `StatCard` changed from a stacked icon/value/label
   block to a compact horizontal icon + value/label + meta row (33 px value).
   Mission Control metric values 28 → 33 px.
5. **Re-verification.** After the edits, every route registered at the time was re-captured and a DOM
   audit checked for clipped text and horizontal overflow at 1600 × 1000. The
   Launch decorative orb was removed in the final polish pass, so no route
   extends past the viewport in either axis.

## Open divergences

None. All 42 surfaces are closed as matched, fixed, or deliberately corrected.
The three former opens (02, 03, 08) were rebuilt against their references and
re-captured. Their live values differ from the reference mocks wherever they
come from the workspace (38 eligible volunteers instead of 82, 410 ledger hours
instead of a composed donut split, two pre-existing arrivals instead of the
reference's illustrative three); those differences are data truth, not design
fallback.

The asset gaps are closed at the level the brief asks for: 02 shows real
volunteer portraits and 03 shows a real dusk city. They are not the mock's own
imagery. At native size 02's six faces, styling and crops read as the same kind
of volunteer directory, but they are different people from the mock's invented
names; 03's skyline is a warmed blue-hour capture, not the mock's orange
sunset composite, so cloud shape and light direction differ. Neither is claimed
as pixel-identical photography.
